# Network Security Dashboard

A real-time monitoring dashboard for network security alerts visualization using React.js and Plotly.js with dark theme.

## Features

- **Alerts Timeline**: Visualize alert frequency over time
- **Top Attack Sources**: Identify most active source IPs
- **Targeted Services**: View service port distribution
- **Severity Distribution**: Analyze alert severity levels
- Dark theme interface
- Responsive design
- Interactive charts
- Real-time data simulation

## Technologies Used

- React.js
- Tailwind CSS
- Plotly.js
- React Plotly
